# fatcorn753

学生です。自分や友達が日常で困ったことを、小さなツールにして解決しています。
Chrome 拡張・VS Code 拡張・Android アプリ・Discord Bot を中心に作っています。

## 作ったもの

**ブラウザ・エディタ拡張**

- [tex-sync-view](https://github.com/fatcorn753/tex-sync-view) — TeX と PDF のスクロールを双方向に連動させる VS Code 拡張
- [random-youtube](https://github.com/fatcorn753/random-youtube) — 人気動画をランダムに流し続け、YouTube をテレビのように見る Chrome 拡張
- [dot_cursor](https://github.com/fatcorn753/dot_cursor) — カーソルをドットにし、追いかけるドットも付けられる Chrome 拡張

**Discord Bot(Python)**

- [discord-casino-bot](https://github.com/fatcorn753/discord-casino-bot) — 仮想通貨「ペリカ」で遊ぶ友達向けのカジノ Bot。自宅サーバーで常駐運用中
- [discord-management-bot](https://github.com/fatcorn753/discord-management-bot) — 日本語のサーバー管理 Bot(処罰・認証・チケット・予約投稿・バックアップ)

**Android(Kotlin)**

- [tabiato](https://github.com/fatcorn753/tabiato) — 歩いた場所を地図のマス目として塗りつぶしていく足跡記録アプリ
- [detox-app](https://github.com/fatcorn753/detox-app) — 許可したアプリだけを、決まった時間だけ使える状態にするアプリ
- [workout-app](https://github.com/fatcorn753/workout-app) — カメラで腕立て伏せの回数を自動で数える記録アプリ

**その他**

- [easyscrape](https://github.com/fatcorn753/easyscrape) — ページ上で要素を選ぶだけで、CSV / JSON に取り出せるスクレイピングツール
- [tsugakuro-risk-score](https://github.com/fatcorn753/tsugakuro-risk-score) — 市川市の通学路の危険区間をスコア化(CODIHA 2026 参加作品)
- [independent-review](https://github.com/fatcorn753/independent-review) — レポートとコードを独立したエージェントに採点させる Claude Code プラグイン
- [github-profile-badge](https://github.com/fatcorn753/github-profile-badge) — 依存なしで動く、プロフィール用の SVG バッジ集(下のバッジもこれ)

## 使っている技術

- 言語: JavaScript, Kotlin, Python, HTML/CSS, Shell
- 開発: Chrome Extension (Manifest V3), VS Code Extension API, Android, discord.py
- AI: Claude Code と Gemini を開発の相棒として使っています。設計の判断と動作確認は自分で行っています
